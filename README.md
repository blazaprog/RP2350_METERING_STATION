# RP2350 Metering Station

Ethernet temperature/humidity/pressure meter: RP2350-POE-ETH (W6300, PoE) + BME280 + 1.3" SH1106 OLED.
Outputs: web page, JSON, Modbus TCP. Language: C (Pico SDK 2.x).

Build: VS Code + Raspberry Pi Pico extension, board `pico2`. See `docs/pinout.md`.

Status: skeleton. W6300 driver, BME280 and SH1106 are still TODO.
